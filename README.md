# FlowLens Charts — Public Assets

This repository holds the **public assets** for the Atlassian Marketplace app
**FlowLens Charts** (Jira dashboard gadgets for agile flow metrics).

## Contents

| Path | Purpose |
|---|---|
| `assets/icons/` | App icon and gadget thumbnails referenced by the app's Forge manifest |
| `docs/privacy-policy.md` | Public privacy policy (Marketplace review requirement) |

## Why a separate public repository?

The application source code lives in a **private** repository. This assets-only
repository stays public because the Atlassian platform requires publicly
reachable URLs for:

- Dashboard gadget thumbnails (loaded from the manifest)
- The privacy policy page

## The app

FlowLens Charts adds six agile flow charts to Jira dashboards — Created vs
Resolved, Sprint Velocity, Time in Status, Cycle Time Scatterplot, WIP Aging
and Cumulative Flow.

See it on the Atlassian Marketplace (link will be added once the listing is live).
